# My Portfolio

個人用の株式・現金記録アプリ。日本株・米国株・投信・ETFを口座名別に管理します。

## 起動・検証

- `python -m http.server 4187 --bind 127.0.0.1`
- `node --test tests/core.test.cjs tests/storage.test.cjs`
- `node --check app.js`

## 計算と保存

- 日付昇順、同日取引は登録順の移動平均。買付手数料を取得原価に含めます。
- 投信の数量は口数。価格単位を明示し、標準表示は1万口当たりです。
- 過去版の投信は既存金額を保存するため1口当たりとして扱い警告します。約定記録に合わせて単価と単位を編集してください。
- 株式・投信の円換算含み損益には現在値と現在の為替を使い、米国資産の取得原価には買付時の為替を使います。取引に買付時レートがない場合は現在の為替で暫定換算し、画面に概算と表示します。証券会社の円建て平均取得単価が分かる場合は銘柄ごとに直接登録でき、その値を優先します。
- 米ドル現金には残高に対応する平均取得レートを任意登録でき、為替損益を別表示します。残高の取得レートがない場合は為替損益を未算出と表示します。売却益・配当・税務計算は未対応です。
- 現金は残高入力。売買による自動増減はしません。
- NISAは取引ごとに口座区分を付けます。非課税枠管理は未対応です。
- 保有銘柄は証券口座別に評価額・含み損益を集計し、口座・資産種類で絞り込めます。価格未設定の銘柄は取得原価で仮評価し、含み損益から除きます。全体の総資産は絞り込みの影響を受けません。
- 株式・ETF、通常の投資信託、つみたてNISA・つみたて投資枠の表示を切り替え、コード・名称・口座・評価額で並び替えできます。
- 毎日積立は設定した開始日から予定を表示します。2026～2027年の日本の祝日は[内閣府の公開日程](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)を同梱しています。ファンド固有の休業日やそれ以降の祝日は除外日に指定してください。予定・注文済み表示は残高に反映せず、実績はCSVまたは手入力で確定します。
- 画面上部の「積立設定」から毎営業日の設定画面を直接開けます。
- 取引追加で数字4〜5桁は日本株、英字ティッカーは米国株としてYahoo Financeから銘柄名を補完します。入力欄を空にしている場合だけ自動取得名を入れます。
- 取引追加画面では、直前に保存した口座名を初期値として再利用します。
- 「口座を管理」から証券口座・銀行口座などを登録できます。取引追加と現金追加では登録済み口座をプルダウンから選べます。既存データの口座名も自動的に候補へ追加します。
- localStorageに端末・ブラウザごとに保存。クラウド同期はありません。
- 保存前に全データを検証。直前データを別キーに保持します。定期的にJSONバックアップを取得してください。
- 復元失敗時は元データを上書きしません。読込不能な元データはバックアップから退避できます。

## CSV

UTF-8またはShift-JIS、ヘッダー必須。列順は自由です。共通形式に加え、SBI証券・楽天証券・moomooで使われる日本語見出しを自動認識します。CSV取込先の口座は画面のプルダウンで選びます。

`date,market,side,symbol,name,quantity,price,fee,account,assetType,priceUnit`

必須はdateからfeeまで。市場JP/US、売買BUY/SELL、資産種類STOCK_JP/STOCK_US/FUND/ETF。米国株の為替レート列は任意で、`fxRate`、`為替レート`、`適用為替レート` などを認識します。米国株の金額・手数料はUSDとして扱うため、円建てCSVは取込前プレビューで必ず確認してください。
投信はpriceUnit必須（通常10000）。未指定口座はその他。
引用符・改行を扱い、不正行は全体拒否。取込前に口数・単価・約定金額を一覧表示し、重複候補は初期状態で選択を外します。取込先口座と口座区分を選べます。
同日同数量の正当な複数約定はCSV内で維持します。時刻情報は保持せず、同日はCSVの行順で計算します。
株式分割・移管・分配金・再投資の自動処理は未対応です。投信CSVは「取込種類」で投資信託を指定できます。証券会社のCSVは形式が変わる場合があり、必須列が足りない場合はエラーを表示します。

## 価格取得の制約

`quote-symbols.json` に掲載した公開銘柄コードだけをGitHub Actionsが日本時間の平日朝・夜に取得し、`quotes-snapshot.json` をGitHub Pagesへ配信します。数量・口座名・取引履歴はこの仕組みに送信しません。アプリは開いたときに配信価格を読み込み、手入力価格や配信より新しい価格を上書きしません。未掲載銘柄は画面の「銘柄コードだけコピー」で一覧を取り出し、`quote-symbols.json` に追記してください。公開リポジトリの更新リストは誰でも閲覧できます。既存の価格は取得元を判別できないため、初回だけ「表示中の価格を更新」で自動取得価格として保存すると、以後の定期更新が反映されます。

手動の「表示中の価格を更新」は、選択中の口座・資産種類だけを対象にします。取得できた価格は1件ずつ保存するので、途中で画面を閉じても保存済み分は残ります。多数の銘柄を手動更新するときは中継への通信を3.5秒以上空けます。HTTP 429（回数制限）では65秒以上待って最大2回再試行します。直接取得と中継には独立したタイムアウトを設定しています。提供元に価格がない銘柄は手入力が必要です。

Yahoo Financeの直接取得はブラウザのCORS制限で失敗する場合があります。通信失敗を確認した後は同じ画面での直接取得を省き、`r.jina.ai` のCORS中継を使います。中継には銘柄コード（例：AAPL、7203.T、USDJPY=X）だけが送信され、数量・口座・取引履歴は送信しません。中継側の停止・遅延・内容変更により取得できない場合があります。
取得タイムアウト・失敗は表示し、既存価格を維持します。投信は下記6本の8桁コードで基準価額の自動取得に対応します。Yahoo!ファイナンス日本版の公開ページを同じ中継で取得し、1万口当たりの価格と基準日を確認します。日中のリアルタイム価格ではありません。その他の投信は手入力です。自動価格を唯一の記録として扱わず、価格と日時を確認してください。

- 2931113C：ニッセイ外国株式インデックスファンド＜購入・換金手数料なし＞
- 9I312179：楽天・全米株式インデックス・ファンド
- 03319172：eMAXIS Slim 先進国株式インデックス（除く日本）
- 03312175：eMAXIS Slim バランス（8資産均等型）
- 03311187：eMAXIS Slim 米国株式（S&P500）
- 0331418A：eMAXIS Slim 全世界株式（オール・カントリー）

## 更新

Service Workerはオンライン優先・オフライン時キャッシュです。他サイトのキャッシュは削除しません。
旧版からの初回移行はサイトを再読み込み後、同サイトのタブ・PWAをすべて閉じて開き直してください。
アプリ削除・サイトデータ消去は不要です。
