# My Portfolio

個人用の株式・現金記録アプリ。日本株・米国株・投信・ETFを口座名別に管理します。

## 起動・検証

- `python -m http.server 4187 --bind 127.0.0.1`
- `node --test tests/core.test.cjs tests/storage.test.cjs`
- `node --check app.js`

## 計算と保存

- 日付昇順、同日取引は登録順の移動平均。買付手数料を取得原価に含めます。
- 投信の数量は口数。価格単位を明示し、標準表示は1万口当たりです。
- 過去版の投信は既存金額を保存するため1口当たりとして扱い警告します。約定記録に合わせて単価と単位を編集してください。
- 含み損益のみ表示。売却益・配当・取得時からの為替差損益・税務計算は未対応。
- 現金は残高入力。売買による自動増減はしません。
- NISAは口座名での分類のみ。非課税枠管理は未対応。
- 取引追加で数字4〜5桁は日本株、英字ティッカーは米国株としてYahoo Financeから銘柄名を補完します。入力欄を空にしている場合だけ自動取得名を入れます。
- 取引追加画面では、直前に保存した口座名を初期値として再利用します。
- 「口座を管理」から証券口座・銀行口座などを登録できます。取引追加と現金追加では登録済み口座をプルダウンから選べます。既存データの口座名も自動的に候補へ追加します。
- localStorageに端末・ブラウザごとに保存。クラウド同期はありません。
- 保存前に全データを検証。直前データを別キーに保持します。定期的にJSONバックアップを取得してください。
- 復元失敗時は元データを上書きしません。読込不能な元データはバックアップから退避できます。

## CSV

UTF-8またはShift-JIS、ヘッダー必須。列順は自由です。共通形式に加え、SBI証券・楽天証券・moomooで使われる日本語見出しを自動認識します。CSV取込先の口座は画面のプルダウンで選びます。

`date,market,side,symbol,name,quantity,price,fee,account,assetType,priceUnit`

必須はdateからfeeまで。市場JP/US、売買BUY/SELL、資産種類STOCK_JP/STOCK_US/FUND/ETF。
投信はpriceUnit必須（通常10000）。未指定口座はその他。
引用符・改行を扱い、不正行は全体拒否。既存と同一の取引があれば重複確認を促し全体拒否します。
同日同数量の正当な複数約定はCSV内で維持します。時刻情報は保持せず、同日はCSVの行順で計算します。
株式分割・移管・分配金・再投資の自動処理は未対応です。投資信託の資産種類はCSVで明示してください。

## 価格取得の制約

多数の銘柄を更新するときは中継への通信を3.5秒以上空けます。HTTP 429（回数制限）では65秒以上待って最大2回再試行します。直接取得と中継には独立したタイムアウトを設定しています。画面には進捗と失敗銘柄・理由が表示されます。50銘柄程度では数分かかるため、更新中はページを開いたままにしてください。提供元に価格がない銘柄は手入力が必要です。

Yahoo Financeの直接取得はブラウザのCORS制限で失敗するため、まず直接取得を試し、失敗時だけ `r.jina.ai` のCORS中継を使います。中継には銘柄コード（例：AAPL、7203.T、USDJPY=X）だけが送信され、数量・口座・取引履歴は送信しません。中継側の停止・遅延・内容変更により取得できない場合があります。
取得タイムアウト・失敗は表示し、既存価格を維持します。投信は下記6本の8桁コードで基準価額の自動取得に対応します。Yahoo!ファイナンス日本版の公開ページを同じ中継で取得し、1万口当たりの価格と基準日を確認します。日中のリアルタイム価格ではありません。その他の投信は手入力です。自動価格を唯一の記録として扱わず、価格と日時を確認してください。

- 2931113C：ニッセイ外国株式インデックスファンド＜購入・換金手数料なし＞
- 9I312179：楽天・全米株式インデックス・ファンド
- 03319172：eMAXIS Slim 先進国株式インデックス（除く日本）
- 03312175：eMAXIS Slim バランス（8資産均等型）
- 03311187：eMAXIS Slim 米国株式（S&P500）
- 0331418A：eMAXIS Slim 全世界株式（オール・カントリー）

## 更新

Service Workerはオンライン優先・オフライン時キャッシュです。他サイトのキャッシュは削除しません。
旧版からの初回移行はサイトを再読み込み後、同サイトのタブ・PWAをすべて閉じて開き直してください。
アプリ削除・サイトデータ消去は不要です。
